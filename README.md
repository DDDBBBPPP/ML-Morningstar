# ⭐ ML-Morningstar

Proyecto de Machine Learning que estima las estrellas de Morningstar (de 1 a 5) de fondos de inversión. Compara un modelo basado en la composición y los costes del fondo con otro que incorpora su historial de rentabilidad y riesgo. Incluye exploración, preparación de datos, entrenamiento y evaluación de modelos con Python y scikit-learn.
